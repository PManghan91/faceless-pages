Privacy Policy

Overview

Faceless is a private workflow used by its owner to publish approved short-form educational videos to the owner's connected TikTok account. It is not a public consumer app.

Information We Process

When the owner connects TikTok, Faceless stores TikTok OAuth token data on the owner's private server so the workflow can refresh access and post approved videos. The workflow also stores video metadata, file hashes, publish status, platform response logs, and operational audit records.

How We Use Information

Information is used only to verify approved media, publish approved videos to TikTok using the Content Posting API, track whether publishing succeeded, troubleshoot failed runs, and prevent duplicate posting.

Sharing

Faceless sends approved video files and post metadata to TikTok when publishing is requested. We do not sell personal information or share OAuth tokens with third parties.

Retention

OAuth token state is retained while the TikTok connection is active. Publish logs and operational records are retained for audit, troubleshooting, and duplicate-prevention purposes unless deleted by the owner.

Revocation And Deletion

The owner can revoke TikTok access in TikTok account settings or request deletion of stored token state and workflow logs. Revoking access prevents future TikTok publishing until a new authorization is completed.

Security

Tokens are stored server-side and are not displayed in the browser. Access to the workflow server is restricted to the owner and trusted operators.

Hosting

This policy page is hosted on GitHub Pages. GitHub may process visitor information, such as IP addresses, as part of providing static site hosting.
